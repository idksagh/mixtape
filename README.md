# MIXTAPE v3 — бесплатный прототип для iPhone

MIXTAPE — персональный музыкальный органайзер с визуальным стилем в духе Apple Music и разделами подборок по настроению.

## Что можно проверить прямо сейчас
- Добавлять треки вручную: название, исполнитель, сервис и ссылка.
- Хранить общую библиотеку треков из Яндекс Музыки, Spotify и SoundCloud.
- Создавать собственные плейлисты и добавлять в них треки из разных сервисов.
- Искать по локальной библиотеке и фильтровать по сервису.
- Добавлять треки в избранное и открывать фильтр «Избранное».
- Открывать ссылку трека в исходном сервисе через мини-плеер.
- Искать музыку по настроению в Яндекс Музыке.
- Экспортировать библиотеку в JSON и импортировать её обратно.
- Нажать «Загрузить примеры для проверки» в настройках: добавятся три демонстрационные ссылки (это не сами аудиозаписи).

## Важно понимать
Это работающий клиентский прототип, но не нативное приложение App Store. Вход в аккаунты и автоматический импорт библиотек не подключены. Встроенного воспроизведения аудио нет: мини-плеер открывает ссылку трека в официальном сервисе. Это связано с ограничениями доступных API и бесплатных тарифов.

## Как запустить на iPhone
Самый надёжный способ — разместить `index.html` и `manifest.json` на HTTPS-хостинге. Это можно сделать бесплатно через GitHub Pages или другой статический хостинг.

1. Распакуй архив.
2. Загрузи `index.html` и `manifest.json` на статический HTTPS-хостинг.
3. Открой полученную HTTPS-ссылку в Safari на iPhone.
4. Нажми «Поделиться» → «На экран Домой».
5. Запусти MIXTAPE с нового значка.

Важно: открытие HTML-файла прямо из приложения «Файлы» на iOS может показать его как документ или предпросмотр, а не как полноценное веб-приложение. Если интерфейс не реагирует на нажатия, открой страницу через HTTPS в Safari.

## Хранение данных
Библиотека хранится локально в браузере на этом устройстве. Очистка данных Safari может удалить библиотеку, поэтому при необходимости делай экспорт JSON в настройках.
